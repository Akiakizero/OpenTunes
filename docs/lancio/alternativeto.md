# Scheda AlternativeTo

- **Nome:** OpenTunes
- **Alternativa a:** NepTunes (e anche: Sleeve, Tuneful, Boring Notch per la parte del notch)
- **Licenza:** Free, Open Source (GPL-3.0)
- **Piattaforma:** Mac
- **Sito:** https://github.com/Akiakizero/OpenTunes
- **Tag:** last.fm, scrobbler, menu bar, now playing, music player controller, widget, notch

**Descrizione breve:** Free and open-source now-playing app for macOS: menu bar, notch player, desktop and
WidgetKit widgets, floating player, and Last.fm/ListenBrainz scrobbling from any player.

**Descrizione lunga:** OpenTunes shows the current track from Apple Music, Spotify, browsers and any app that
publishes to the system Now Playing, and lets you control it from the menu bar, a player around the notch,
a live desktop widget, macOS widgets with interactive buttons, a floating Liquid Glass window and the Dock icon.
It scrobbles to Last.fm and ListenBrainz with an offline queue and title clean-up, and supports love, star ratings
and add-to-library for Apple Music.
